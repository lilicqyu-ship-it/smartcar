## 1. 线程模型（解耦的架构保证，spec §74-76）

```
LVGL 任务（BSP bsp_display_start_with_config：栈 9216 B、绑核 1）
 ├─ 100 ms 周期定时器：app_state_snapshot → 告警覆盖层 + 当前页刷新
 │    （全部经 ui_label_set_text/fmt 缓存写入——值不变不触碰对象，
 │      否则 10 Hz 无效重绘让 RGB bounce-buffer 供帧持续满载 → 屏幕抖动）
 ├─ 触摸/按钮事件回调（摇杆、STOP、设置控件）
 └─ 页面切换（单层导航，无跨任务对象访问）

scr_ctrl 任务（核 1，prio 5 > LVGL 4）：30 Hz，发送 try-only（见 04 §7），
   微秒级突发，不受 UI 负载影响也不阻塞 UI
scr_link 任务（核 0，网络侧）：不持有任何 LVGL 对象
跨任务通道：唯一 = app_state 快照（互斥拷贝，见 01 §3）
```

刷新分级（spec §75）：驾驶控制 30 Hz（ctrl 任务直发，不过 UI）、UI 值刷新
10 Hz、Radio 统计 1 Hz、静态信息仅 on_show。**没有任何 50 Hz 全量刷新路径**。

## 3. P1 驾驶主页（spec §70/§110 布局）

```
┌──────────────────────────────────────────────┐
│ SMART CAR          ● CONNECTED   [⚙]         │  顶栏 52 px：连接态(色+字) / 控制权
├──────────────────────────────────────────────┤
│ ┌─ 左列 36 % ─────────┐  ┌─ 摇杆区 ───────┐ │
│ │ SPEED               │  │                │ │
│ │ +1.25   (48 px)     │  │    大摇杆      │ │  flex 布局随分辨率伸缩
│ │ THROTTLE/STEER      │  │  (≤340 px)     │ │
│ │ BAT/MODE/STATE 行   │  │                │ │
│ │ RSSI/LAT/LOSS 行    │  └────────────────┘ │
├──────────────────────────────────────────────┤
│                  [ STOP ]                    │  底部固定 56 px，红，宽 ~33 %
└──────────────────────────────────────────────┘
```

- 信息**色+图标+文字**三重表达（§51/§11）：CONNECTED/STALE/CONNECTING/
  SEARCHING；S3 MASTER / NO CONTROL；READY/DRIVING/STOPPED/WARNING/FAULT/
  EMERGENCY。
- **模式一键切换**：信息行模式值可点，点击在 ECO→NORMAL→SPORT 间循环 +
  Toast 反馈（spec §33/§34，驾驶中 1 次触摸完成，不进设置页）。
- 过期数据处理（§101/102）：遥测过期 → 速度 `--`（含慢速倒车符号修正：
  -50 mm/s 显示 `-0.05` 而非 `+0.05`）；连接在但无数据 → STALE。
- STOP 按钮固定底部中央不随页面变化（§18）；按下时长在 UI 内计时，
  松开时分流单击/急停（§19）；RELEASED 无 PRESSED 配对（如按压中弹出
  覆盖层）一律按单击处理，防误触发急停。

## 4. 虚拟摇杆（ui_joystick，spec §13-16）

- 视觉：外圈 + 四向刻度 + 中心点 + 高亮旋钮（**3 px 描边而非模糊阴影**——阴影
  随拖动逐像素混合，是面板上最重的渲染路径，实测拖动闪烁 R-9）。
- 旋钮像素更新带 2 px 滞回（PRESSING 每次输入轮询都到达，坐标未变不重绘）；
  **控制输出不受滞回影响**，仍按触摸原始坐标全速率计算。
- **输入门控（失效保护）**：Home 页 10 Hz 下发
  `ui_joystick_set_enabled(conn==CONNECTED && owner==S3)`。门关闭时：输入
  全零、旋钮强制回中、控件置灰（不可驾驶的视觉语言，spec §104）；**拖动中
  失链不会留下"陈旧倾斜量"**——链路恢复时若手指仍停在盘上，摇杆保持惰性，
  抬手重按才恢复，杜绝恢复瞬间复出行驶指令。
- 门开启时：`PRESSING` 取屏坐标 → 相对中心、钳位到最大半径；
  **径向死区**（按压起始时从设置采样）+ 死区边缘线性重映射：
  `scale=(r-dz)/(1-dz)`，`v=-dy/r·scale·600`，`w=-dx/r·scale·300`（上=前进）。
- 释放：160 ms ease-out 回弹动画 + 输入归零；按压即调
  `scr_ctrl_joystick_touch()`（STOP 锁存的显式再接管，仅门开启时）。
- Throttle/Steering 实时百分比显示在主页（来自 `out_v/out_w`，§16：让用户
  看见"油门非零"）。

## 5. 告警覆盖层（P9，spec §20-22/§63）

- `lv_layer_top()` 全屏模态：等级配色（CRIT 红/WARN 琥珀/NOTICE 蓝）+ 红色
  边框（急停态 §63）+ 图标 + 标题 + 正文 + 动作按钮。
- 按钮语义：`id==EMERGENCY` → **[RELEASE]**（调 `scr_ctrl_emergency_release`）；
  其余 → **[ACKNOWLEDGE]**（`app_alert_ack`，条件解除仍由 raise/clear 管理）。
- 等级门槛：仅 WARNING/CRITICAL 进覆盖层；RSSI 低等提示只走状态栏（§22）。

## 6. 主题与字体层级（spec §51-54）

深色主题（§52）：`#0E1116` 底 / `#1A2029` 卡片 / 亮字 `#E8ECF1`；
语义色 OK `#34C77B` / WARN `#F5B944` / CRIT `#F5475B` / INFO `#4D9FFF` /
ACCENT `#2FA4FF`。

字体四级（§54）：48 px（速度）→ 28 px（STOP/标题）→ 20 px（页标题）→
16/14 px（值/说明/Diagnostics）。图标统一 LVGL 内置符号集（一阶段，§55
统一视觉语言）。

## 9. 已知限制与风险

1. **LVGL 任务栈已提升至 9216 B**（原 BSP 默认 7168），Settings+键盘页的
   最深调用路径留有余量；真机仍应读 `uxTaskGetStackHighWaterMark` 复核。
2. Event Log 列表整列表重建（32 条上限，1 Hz 内触发，成本可控）。
3. 图标为 LVGL 符号字体，开机页"小车"占位符是通用图标——正式视觉资产
   （SVG→C 数组）属 spec §92 UI Phase 6。
4. 主页信息行约 10 个 label 每 100 ms 重设文本（值变化才重绘出内容，但
   invalidate 每次发生）；800×480 RGB + bounce-buffer 下余量充足，
   若真机测出帧率问题再按字段缓存。
