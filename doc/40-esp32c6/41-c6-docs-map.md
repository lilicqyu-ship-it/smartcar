## 4. 现状提醒（别把已接线当成已启用）

`23 §9.1` 的 SPI 五行 + 共地**实物已接好**，**两侧固件代码也都已改为 SPI**（C6 侧 `c6_car` `22e15f2`；TC275 侧 `com/`，**Debug 与 Release 两个 TASKING 配置都已定义 `USE_SPI_LINK`——UART 板间链路于 2026-09-26 弃用，见 `21 §5.6` 末条与 `21 §18 C15`**，UART 分支只在手动删除该符号时才编译，见 `32 §1`）。但**这条链路从未通电跑过**：TC275 侧编译链接已闭合（2026-09-26），板上实际刷的镜像仍未验证。**后果（C6 侧要一起认）**：G1 失败时不再有"刷回 esp-at 就能通"的单向退路——恢复 UART 需要 TC275 删符号重编 + C6 重刷 esp-at 两侧动作，`c6_car` 的构建/文档若把 UART 当作现成回退通道来写，口径已过期。

**电气形态（2026-09-26 已确认，coding 必读）**：两板之间**所有相连引脚都是杜邦线直连，没有任何外部电阻**（无上拉/下拉/串阻/端接/电平转换），真源见 `23 §9.3` 与 SDD `§18 C14`。对 IRQ（GPIO21 → P23.0）这条线的直接后果：

- 唯一上拉是 **TC275 片内** `IfxPort_InputMode_pullUp`；C6 侧 `c6_car/components/c6_link/link.c` 以开漏输出且显式写了 `GPIO_PULLUP_DISABLE`，其"`/* external 10k (22 §3.2) */`"注释与实物不符，**待该仓库更正**。
- 握手是**电平轮询**（P23.x 做不出边沿中断，22 §3.1 E11），且片内上拉驱动能力弱、线又长，电平边沿慢且可能带毛刺：只采样静态电平，不做边沿计数/消抖状态机。
- **判活只看 `SF_ALIVE`**：`IRQ 高 ≠ 从机在位`，`MISO 读回 0x00/0xFF ≠ 应答`（那是浮空/默认值，不是回答）。
