# SMART CAR REMOTE — 用户操作手册（LCD UI 详解）

> 适用设备：ESP32‑S3 LCD‑EV‑Board 远距离智能遥控器（800×480 触摸屏）
> 本手册面向操作者，逐屏说明界面上每一项数据的含义与每一个设置的作用。
> 术语约定：**遥控器 / S3** 指手上这块屏；**小车 / TC275** 指被控车辆；
> **C6** 指小车上的 Wi‑Fi 网关模块。数据链路为：遥控器 S3 ⇄（Wi‑Fi）C6 ⇄ 小车 TC275。

## 1. 开机自检页（Boot）

上电后首先出现「SMART CAR / REMOTE CONTROLLER」标题页，中部是一条进度条与四项自检清单：

| 自检项 | 含义 | 通过标志 |
|---|---|---|
| **LCD** | 屏幕显示子系统就绪 | 右侧变绿色 ✓ |
| **Touch** | 触摸控制器就绪 | 右侧变绿色 ✓ |
| **Radio** | Wi‑Fi 无线电就绪 | 右侧变绿色 ✓ |
| **System** | 系统任务与状态机就绪 | 右侧变绿色 ✓ |

- 未通过项显示灰色「‑」，通过后变绿色对勾，进度条同步推进（满格 = 4/4）。
- 四项全部通过约 **0.6 秒** 后自动切换到驾驶主页，无需任何操作。
- 若某项长时间停在灰色「‑」，说明该子系统未就绪（见 [常见问题排查](#14-常见问题排查)）。

## 2. 驾驶主页（Home）— 核心操作屏

这是日常驾驶使用的主界面。整体布局为**左右两块**：左侧是 320 px 宽的控制列（顶栏、速度卡、模式选择、遥测栏、STOP）；右侧是占满整个屏高的 480×480 方形**摇杆区**，让右手拇指拥有最大的操纵面积，摇杆外圈由三段 HUD 圆弧环绕。

```
┌───────────────┬─────────────────────────────────┐
│ SMART CAR  [⚙] │ THR +30%               ↑ FWD   │
│ REMOTE CONSOLE │    ╭───── SPD 弧 ─────╮        │
│ CONNECTED      │ ╭──┤                   ├──╮    │
│ S3 MASTER      │ │  │      摇杆          │  │    │
│                │THR │   （480×480）      │STR│    │
│ SPEED          │ 弧 │                   │ 弧│    │
│ +1.25  m/s     │ ╰──┤                   ├──╯    │
│                │    ╰───── STR 弧 ──────╯        │
│ DRIVE   │BATT  │ STR -10%              ↓ REV    │
│ [ECO]   │STATE │                                 │
│ [NORMAL]│RSSI  │                                 │
│ [SPORT] │PING  │                                 │
│         │LOSS  │                                 │
│ [  STOP  ]     │                                 │
└───────────────┴─────────────────────────────────┘
   左侧控制列 320 px        右侧全高方形摇杆区
```

### 2.1 顶栏（左列顶部）

| 元素 | 含义 | 取值与颜色 |
|---|---|---|
| **SMART CAR / REMOTE CONSOLE** | 产品标题（固定） | — |
| **连接状态**（右上第一行） | 遥控器与小车的链路状态 | `SEARCHING`(灰) 搜索中 · `CONNECTING`(蓝) 连接中 · `CONNECTED`(绿) 已连接且数据新鲜 · `STALE`(琥珀) 连着但遥测超时（>0.6 s 无帧） |
| **控制权**（右上第二行） | 当前谁在操控这辆车 | `S3 MASTER`(绿) 本遥控器持有控制权 · `WEB MASTER`(蓝) 手机网页端持有控制权 · `NO CONTROL`(琥珀) 无人控制 |
| **齿轮 ⚙** | 进入设置（指挥台） | 点击打开 |

> **关键规则**：只有当状态为 `CONNECTED` **且** 控制权为 `S3 MASTER` 时，摇杆才可驱动小车。其余情况下摇杆变灰、不可用（失效保护）。

### 2.2 SPEED（速度）卡

- 大号数字为当前车速，单位 **m/s**，带符号：`+` 前进、`-` 倒车（例如 `-0.05` 表示低速倒车）。
- 数据超时（`STALE` 或断链）时显示 `--`（灰色），绝不显示过期的假数据。

### 2.3 DRIVE MODE（驾驶模式）选择列

左列中下部是三个纵向排布的模式按钮 **ECO / NORMAL / SPORT**：

- 当前模式高亮（青色描边 + 底色）。
- **轻点任意一个按钮即直接选定该模式**（不是循环切换，不会误经过不想要的模式），并弹出底部 Toast 提示（如 `SPORT MODE`，约 1.4 秒后自动消失）。
- 模式含义见 [§5.1 DRIVE TUNING](#51-control--drive-tuning驾驶调校)。

### 2.4 遥测栏（BATTERY / STATE / RSSI / PING / LOSS）

模式列右侧的遥测卡自上而下五格，每格为「小标题 + 数值」：

| 格 | 含义 | 说明 |
|---|---|---|
| **BATTERY** | 小车电池电量 % | 绿=正常 · 琥珀=低电（≤20%）· 红=极低（≤10%）；数值下方还有一条与电量等长的细进度条；无数据显示 `--` |
| **STATE** | 车辆系统状态 | 见下表 |
| **RSSI** | 无线信号强度（dBm） | 数值越接近 0 越强；小标题带质量词 `RSSI EXC / GOOD / FAIR / WEAK / CRIT`，颜色随质量变化 |
| **PING** | 遥控器⇄C6 的往返延迟（ms） | 越低越好；未连接时 `--` |
| **LOSS** | 遥测丢包率（%） | 越低越好；未连接时 `--` |

**STATE（车辆状态）取值：**

| 显示 | 含义 | 颜色 |
|---|---|---|
| `BOOT` | 启动中 | 灰 |
| `LINKING` | 建立链路中 | 琥珀 |
| `READY` | 就绪，可驾驶 | 绿 |
| `DRIVING` | 行驶中 | 绿 |
| `WARNING` | 警告状态 | 琥珀 |
| `FAULT` | 故障 | 红 |
| `STOPPED` | 已停车锁定 | 灰 |
| `E-STOP` | 紧急停止 | 红 |

### 2.5 摇杆区与 HUD 圆弧

右侧摇杆区是全屏高的正方形，摇杆本体居中，外围三段圆弧构成 HUD：

| 弧 | 位置 | 显示内容 | 颜色 / 量程 |
|---|---|---|---|
| **THR 弧** | 左侧 | 实际发送的油门 % | 青，`-100% ~ +100%` 中心对称 |
| **STR 弧** | 底部 | 实际发送的转向 % | 蓝，`-100% ~ +100%` 中心对称，`+` 右转、`-` 左转 |
| **SPD 弧** | 顶部 | 车速幅度（满量程 0.6 m/s 的百分比） | 绿，`0 ~ 100%` |

- 弧旁的数字读数位于摇杆区左上（`THR +30%`）与左下（`STR -10%`），右上 / 右下标有 `↑ FWD`、`↓ REV` 方向提示。
- THR / STR 显示的是遥控器**实际发送出去**的控制量（不是摇杆的原始位置），并按 **30 Hz** 跟随手指实时刷新，让你直观看到「油门是否非零」，避免误以为已停车实则仍有输出。
- 摇杆盘面上有十字导向标、中心点与最大偏移圈（细线圆），便于对中。

**摇杆操作规则：**

- **可用条件**：`CONNECTED` + `S3 MASTER`。满足时旋钮与外圈为青色高亮；否则整体置灰、无法输入。
- **操作**：手指按住旋钮拖动。向上 = 前进，向下 = 后退；向右 = 右转，向左 = 左转。
- 松手后旋钮自动回弹到中心（约 160 ms 动画），控制量立即归零。
- **死区**：中心附近有一圈「死区」，在其中移动不产生输出，用来避免手指微抖导致小车缓行；死区为径向判定，出死区后输出从 0 线性上升。死区大小可在设置中调整（见 §5.1）。
- **STOP 之后再驾驶**：按过 STOP 后，需**重新触摸摇杆**才会重新接管控制（防止松手误动）。
- **失链保护**：拖动中若断链，摇杆立即失效并回中；即使手指仍停在盘上，链路恢复后也不会突然复出行驶指令，必须抬手重按。

### 2.6 STOP 按钮（左列底部红色）

STOP 是安全核心，固定在左列底部：

| 操作 | 效果 |
|---|---|
| **轻点（短按）** | 普通停车：立即让小车停下并锁定，需重新触摸摇杆再驾驶 |
| **长按 ≥ 1.2 秒** | **紧急停止（E‑STOP）**：触发急停，弹出全屏告警，必须显式点击 [RELEASE] 才能解除 |

> 长按时长在遥控器内部计时；松开时判定是短按还是长按。若按压过程中被告警覆盖层挡住导致丢失按下事件，一律按短按处理，绝不会误触发急停。

## 3. 告警覆盖层（Alert）

当发生**安全相关**事件时，全屏弹出告警（普通信息不会弹，只在状态栏体现）。覆盖层带彩色背景 + 红色边框 + 图标 + 标题 + 说明 + 动作按钮。

| 告警等级 | 背景色 | 触发举例 |
|---|---|---|
| CRITICAL（严重） | 红 | 紧急停止、车辆故障 |
| WARNING（警告） | 琥珀 | 电量过低等 |
| NOTICE（提示） | 蓝 | 配对相关等 |

**动作按钮语义：**

- **[RELEASE]**（仅急停时）：解除紧急停止状态。
- **[ACKNOWLEDGE]**（其余告警）：确认知晓；若引发条件仍在，后续可能再次弹出。
- **无按钮（RADIO LOST 无线电丢失）**：链路完全丢失时不显示按钮——因为此时无可确认，告警会一直显示直到链路自动恢复。

## 4. 设置 · 指挥台（Command Deck）

点击主页右上齿轮 ⚙ 进入。页头为 **COMMAND DECK**（带返回主页按钮），左侧是 **SYSTEM CORE** 实时仪表，右侧是**模块磁贴**。

### 4.1 SYSTEM CORE（左侧圆环仪表）

| 元素 | 含义 |
|---|---|
| **圆环 + 中心数字** | 链路信号强度（dBm），圆环按 −90 dBm=0% ~ −40 dBm=100% 映射（270° 扫掠），颜色随质量变化 |
| **质量词** | `NO SIGNAL / EXCELLENT / GOOD / FAIR / WEAK / CRITICAL` |
| **LINK 芯片** | 遥控器⇄C6 链路：`LINK ON`(绿) / `LINK ...`(琥珀，连接中) / `LINK OFF`(灰) |
| **CAR 芯片** | C6⇄小车 链路：`CAR ON`(绿) / `CAR OFF`(灰) |
| **CTRL 芯片** | 控制权：`CTRL S3`(绿) / `CTRL WEB`(蓝) / `CTRL --`(琥珀) |
| **底部信息行** | 开机时长 `UP hh:mm:ss`、无线信道 `CH`、S3 固件版本、C6 固件版本 |

### 4.2 模块磁贴（右侧）

每块磁贴显示编号、图标、名称与**当前值副标题**（无需进入即可看到当前设置）：

| 磁贴 | 进入内容 | 副标题示例 |
|---|---|---|
| **01 CONTROL** | 驾驶调校（模式 + 死区） | `NORMAL  /  DZ 8%` |
| **02 RADIO** | 无线电链路与热点凭据 | 当前 SSID 或 `not set` |
| **03 PAIRING** | 与小车配对 | `Bind to a car` |
| **04 SYSTEM** | 系统拓扑与版本 | `Topology  /  v1.0.0` |
| **05 FIRMWARE** | C6 / TC275 固件更新 | `C6 empty / TC empty`（暂存状态实时更新） |
| **06 CALIBRATE** | TC275 编码器标定 / 电机点动 | `TC275 encoders / jog` |
| **07 DIAGNOSE** | C6 + TC275 健康诊断 | `C6 + TC275 health` |
| **08 DIAG**（工程模式） | 诊断内部信息 | `Link + vehicle internals` |
| **09 EVENTS**（工程模式） | 事件日志 | `Event log` |

> DIAG 与 EVENTS 磁贴默认隐藏，仅在**工程模式**下出现（解锁方法见 §5.3）。

## 5. 设置子页详解

### 5.1 CONTROL — DRIVE TUNING（驾驶调校）

页面分三块，让你**看到设置的效果**而不只是一个数字：

**① 三张模式卡（MODE 01–03）**，轻点即选定：

| 模式卡 | 描述 | 输出上限（OUTPUT CAP） |
|---|---|---|
| **ECO** | Gentle, learning（温和、练习用） | **50%** |
| **NORMAL** | Balanced daily（日常均衡） | **80%** |
| **SPORT** | Full power（全动力） | **100%** |

每张卡上用进度条直观画出输出上限；当前选中卡青色高亮。

**② DEAD ZONE（死区）卡**：摇杆轮廓内画着一个**按比例的琥珀色死区圆盘**——拖动滑条时圆盘实时变大变小，所见即所得。滑条 `0% ~ 30%`，默认 8%。

**③ RESPONSE CURVE（响应曲线）卡**：绘制「摇杆偏移 → 实际输出」曲线（死区内平直为零，出死区后线性升至所选模式上限），旁边文字总结当前效果，例如：

> SPORT mode
> No motion below 8%
> Full stick = 100% power

- 模式为**遥控器端的软限幅**，实际动力调校在车辆端完成。
- 死区在**按下摇杆的瞬间**采样生效；拖动滑条实时显示数值，松手后保存到设备（掉电不丢）。

### 5.2 RADIO — RADIO LINK（无线电链路）

左右两张卡，凭据改动对链路的影响在同一屏即可看到：

**LIVE SIGNAL（左侧，实时信号）**

| 元素 | 含义 |
|---|---|
| **信号条 ×5** | 图形化信号强度，随质量点亮并着色 |
| **大号 dBm 数值** | 当前 RSSI |
| **质量词** | `EXCELLENT / GOOD / FAIR / WEAK / CRITICAL / NO SIGNAL` |
| **NETWORK** | 当前连接的热点 SSID |
| **CHANNEL** | Wi‑Fi 信道号 |
| **ROUND TRIP** | 遥控器⇄C6 往返延迟（ms） |
| **LOSS** | 遥测丢包率 % |
| **TX / RX** | 每秒发送 / 接收帧数 |

**VEHICLE HOTSPOT（右侧，车辆热点）**

| 元素 | 作用 |
|---|---|
| **SSID** | 小车 C6 网关的 Wi‑Fi 名称（出厂默认 `SD-DEV000`，量产机看车身标签） |
| **PASSWORD** | 该 Wi‑Fi 的密码（密文显示） |
| **[APPLY + RECONNECT]** | 保存 SSID/密码并立即重连 |
| **[PAIR WITH VEHICLE]** | 发起与小车的配对（等同配对页的按钮） |
| **状态行** | 显示当前配对/连接反馈 |

- 点击输入框弹出软键盘；点击别处收起（在两个输入框之间切换时键盘不会闪隐）。
- 设置保存到设备内部存储（NVS），重启后依然生效；输入框只在进入页面时填充一次，刷新不会干扰打字。

### 5.3 SYSTEM（系统拓扑 / 关于）

本页不再是一张参数表，而是把真实链路 **S3 → C6 → TC275** 画成三张节点卡加两条连线：

| 节点卡 | 角色 | 版本显示 | 状态字 |
|---|---|---|---|
| **ESP32-S3** | REMOTE / HMI | `vX.Y.Z` | `ONLINE` / `ONLINE  CTRL`（持控制权） |
| **ESP32-C6** | GATEWAY / AP | `vX.Y.Z` | `ONLINE` / `UNREACHABLE` |
| **TC275** | VEHICLE MCU | 双行：`APP vX.Y.Z` + `SBL vX.Y.Z` | `ONLINE` / `FAULT` / `STALE` / `OFFLINE` |

- 节点之间的两条链路实时着色：**WS**（S3⇄C6，Wi‑Fi）与 **SPI**（C6⇄TC275），各显示 `LIVE` / `DOWN`。
- 每张节点卡右上有一个状态点，颜色与状态字一致。

**点击节点卡可刷新该节点的固件版本**（tap‑to‑refresh）：

| 节点 | 刷新方式 | 反馈 |
|---|---|---|
| S3 | 本地读取，立即返回 | `UPDATED` |
| C6 | 经链路向 C6 查询（约 3 s 超时） | `CHECKING...` → `UPDATED` / `NO REPLY` |
| TC275 | 经 C6 向 TC275 请求版本信标（约 6.5 s 超时） | `CHECKING...` → `UPDATED` / `NO BEACON` |

底部为遥测条：**UPTIME**（开机时长）、**INTERNAL RAM**（剩余内存）、**PSRAM**（剩余 PSRAM）、**LINK RTT**（链路往返延迟）。最底一行显示构建信息（构建日期 / IDF 版本），并提示 `TAP S3 x7 FOR ENGINEER MODE`。

> **工程模式解锁**：在 3 秒内连续点击 **S3 节点卡 7 次**，即弹出 `ENGINEER MODE ON` 提示，设置指挥台随即多出 DIAG 与 EVENTS 两个磁贴。

## 6. 固件更新页（FIRMWARE）

对小车侧两个节点（C6 网关、TC275 主控）做 OTA 固件更新。页面左右两张卡 + 底部状态卡：

**① C6 GATEWAY / TC275 VEHICLE 两列**，每列显示：

| 项 | 含义 |
|---|---|
| **RUNNING** | 该节点当前正在运行的固件版本 |
| **STAGED** | 遥控器暂存分区内的待更新镜像：`EMPTY`(灰，无暂存) / `INVALID`(琥珀，校验失败) / `VERIFIED`(绿，可用) |
| **IMAGE VER** | 暂存镜像的版本号 |
| **SIZE** | 暂存镜像大小（KB） |
| **CRC32** | 暂存镜像校验值 |
| 提示行 | 不能更新时的原因（无暂存 / 需要活动的 CTRL 链路 / TC275 链路断开） |

**② UPDATE 按钮（按住确认）**：更新是危险操作，按钮采用**按住 2 秒确认**——按住后按钮上实时倒计时（如 `HOLD 1.4s`），中途松开即取消。按钮仅在以下条件全部满足时可用：

- 暂存镜像为 `VERIFIED`；
- 遥控器已连接且持有控制权（TC275 更新还要求 C6⇄TC275 链路在线）；
- 当前没有别的更新正在进行。

**③ UPDATE STATUS（状态卡）**：

| 元素 | 含义 |
|---|---|
| **阶段** | `IDLE` / `VERIFYING IMAGE`(校验镜像) / `UPLOADING`(S3→C6 上传中) / `TC275 WRITING`(C6→TC275 写入中) / `COMPLETE` / `FAILED` |
| **UPLOAD 进度条** | 遥控器 → C6 的传输进度 |
| **TC275 进度条 + %** | C6 → TC275 的写入进度（仅更新 TC275 时显示） |
| **消息行** | 当前进行到的细节 |
| **[RESCAN]** | 重新扫描暂存分区（更新过程中禁用） |

**镜像从哪来（PC 侧操作，一次性）**：用 USB 线连接遥控器，在电脑上把签包后的镜像写入遥控器暂存分区：

```
smartcar_remote/tools/stage_fw.py --target c6|tc275 --image <镜像> --version <版本> --port <串口>
```

或直接在仓库根目录执行 `python firmware/fw.py ota <project>`——自动编译、打签包并经 USB 暂存进遥控器，随后在本页按住 UPDATE 推送即可（`--direct` 为 PC 直推模式，不经遥控器）。

> 更新过程中请保持遥控器与小车供电稳定；TC275 的镜像由 C6 转发写入，期间 `TC275 WRITING` 阶段耗时较长属正常。

## 7. 标定页（CALIBRATE）

TC275 编码器标定与电机点动。**所有操作都有前置条件门禁**：

**PRECONDITIONS（前置条件）卡**，三项全绿才允许操作：

| 前置条件 | 判定 |
|---|---|
| **CTRL LINK** | 遥控器已连接且持控制权 |
| **TC275 ONLINE** | C6⇄TC275 链路在线 |
| **WHEELS OFF GROUND** | 一个**开关**，必须由操作者亲手打开，确认四个车轮已离地悬空 |

任一条件不满足（或急停锁定中），本页全部按钮禁用；点动中若条件丢失会**立即自动停止**。离开本页时点动自动停止、「车轮离地」开关自动复位，下次进入需重新确认。

**ENCODER DIRECTION（编码器方向）卡**：

- **[RUN（按住 1.5 s）]**：让车轮短暂转动并统计各轮编码器计数。运行中状态行提示「车轮会短暂转动」。
- 结果按轮显示（FL/FR/RL/RR）：`NORMAL`(绿) 方向正确 / `INVERTED`(琥珀) 需反接 / `NO COUNT`(红) 无计数（接线问题），以及计数值 COUNTS。
- 完成后状态行显示 `DONE - saved`（已保存到车端）/ `ABORTED (E-STOP)` / `BUSY`；3 秒无回复会提示检查 TC275 串口 `ENCCAL` 输出。

**RECORD（标定记录）卡**：

| 项 | 含义 |
|---|---|
| **SOURCE** | 记录来源：`DEFAULT`(出厂默认) / `DFLASH`(车端闪存) / `ONLINE`(在线读取) |
| **CRC** | 记录校验 `OK` / `BAD` |
| **INVERT** | 四轮方向映射，如 `+-+-` |
| **FULL SCALE** | 编码器满量程，`- / +` 按钮调整（步进 50，范围 100–5000） |
| **WHEEL mm** | 车轮直径毫米，`- / +` 按钮调整（步进 1，范围 30–200） |
| **[READ] / [WRITE]** | 从车端读取 / 把修改写回车端（改动过才可写） |
| **[DEFAULTS（按住）]** | 按住 1.5 s 恢复出厂默认记录 |

**MOTOR JOG（电机点动）卡**：四个轮（FL/FR/RL/RR）各有 ◀ ▶ 两个方向键——**按住**即以 30% 功率转动该轮，**松开**停止。用于验证电机接线与转向。

> ⚠️ 标定与点动都会让车轮转动，务必先架空小车再操作。

## 8. 诊断页（DIAGNOSE · C6/TC275）

一站式健康诊断，分三张卡：

**HEALTH（健康结论）卡**：

- 大字结论：`NOMINAL`(绿，一切正常) / `ATTENTION`(琥珀，有需关注项) / `FAULT`(红，有故障)。
- 下方列出具体发现（最多 8 条，按严重度着色），例如：无 Wi‑Fi/WS 链路、C6 诊断不应答、C6 上次复位原因异常（看门狗 / 掉电 / PANIC）、C6 存有崩溃转储、C6⇄TC275 SPI 链路断开、SPI CRC/格式错误上升、C6 内存偏低、C6 IMU（ADXL345）错误、TC275 遥测过期、TC275 故障码、电池电量低、左/右侧速度跟踪偏差（并提示去做 CALIBRATE）。
- **[REFRESH]** 立即向 C6 拉取一次诊断；**[CLEAR FAULT]** 向 TC275 发送清除故障指令（是否清除由 TC275 决定）。
- 进入本页自动开始周期轮询，离开即停止。

**C6 GATEWAY 卡（12 行）**：FIRMWARE、STATE、SLOT（运行分区，`(F)` 表示出厂分区）、LAST RESET（上次复位原因）、SELF‑CHECK、COREDUMP（崩溃转储有无）、HEAP MIN（历史最低剩余内存）、UPTIME、SPI LINK、LINK RTT、CRC / FMT ERR、CLIENTS / IMU。

**TC275 VEHICLE 卡（13 行）**：TELEMETRY（`LIVE`/`STALE`/`OFFLINE`）、STATE、FAULT、FIRMWARE、HW REV、BATTERY、LEFT T/M 与 RIGHT T/M（目标/实测速度，mm/s）、ODO SESSION（本次会话里程）、ODO TOTAL（总里程）、LINK RTT、LINK ERR、SBL（引导装载器版本）。

## 9. 车辆信息页（Vehicle）

集中显示小车侧的详细遥测。数据超时时全部显示 `--`。

**DRIVE（驾驶）**

| 项 | 含义 |
|---|---|
| **State** | 车辆原始状态码 `0x??`，末尾 `(no link)` 表示 C6 与小车链路断开 |
| **Speed** | 车速 m/s（带符号） |
| **Throttle** | 实际发送的油门 % |
| **Steering** | 实际发送的转向 % |
| **Mode** | 当前驾驶模式 |

**POWER（动力）**

| 项 | 含义 |
|---|---|
| **Battery** | 电量 % |
| **Battery voltage** | 电池电压 V |
| **Odometer (session)** | 本次会话里程（m） |

**VEHICLE CORE（车辆核心）**

| 项 | 含义 |
|---|---|
| **Fault** | 故障码：`NONE`(绿) 无故障 / `0x????`(红) 有故障 |
| **TC275 firmware** | 小车主控固件版本 |
| **HW revision** | 硬件版本号 |

## 10. 无线电页（Radio）

展示链路质量的完整明细。

| 项 | 含义 |
|---|---|
| **状态行** | `SEARCHING/CONNECTING/CONNECTED/STALE` |
| **RSSI** | 信号强度 dBm + 图形条（−100 dBm→0%，−40 dBm→100%），颜色随质量 |
| **Quality** | 质量词 `EXCELLENT/GOOD/FAIR/WEAK/CRITICAL` |
| **Latency (S3‑C6)** | 遥控器⇄C6 延迟：当前值，及括号内 `min/max` |
| **Loss** | 遥测丢包率 % |
| **TX rate** | 每秒发送的 DRIVE 控制帧数（Hz） |
| **RX rate** | 每秒接收的遥测帧数（Hz） |
| **SESSION：Telemetry seq** | 最新遥测端到端序号 |
| **SESSION：Channel** | Wi‑Fi 信道号 |
| **SESSION：Peer (C6 fw)** | C6 网关固件版本 |
| **SESSION：C6‑TC275 RTT** | C6 与小车间链路往返时延（ms），括号内为错误率 % |

**信号质量阈值（出厂默认，量产前需实测标定）：**

| 质量 | RSSI 门限 |
|---|---|
| EXCELLENT | ≥ −60 dBm |
| GOOD | ≥ −67 dBm |
| FAIR | ≥ −75 dBm |
| WEAK | ≥ −85 dBm |
| CRITICAL | < −85 dBm |

## 11. 配对页（Pairing）

将遥控器绑定到一辆小车。三步引导画成一条「电路」，每个节点满足条件即点亮（青色），你能随时看到流程卡在哪一步：

```
 ① CAR IN RANGE ──── ② HOLD CAR BUTTON 3S ──── ③ TAP PAIR
```

| 步骤 | 操作 |
|---|---|
| ① **CAR IN RANGE** | 给小车上电并保持在通信范围内（节点在连上后点亮） |
| ② **HOLD CAR BUTTON 3S** | 长按小车上的配对按钮 3 秒，开启配对窗口 |
| ③ **TAP PAIR** | 在窗口开启期间，点击本页的 **[PAIR WITH VEHICLE]** |

下方状态卡显示：

- **PAIRED**(绿) / **NOT PAIRED**(琥珀) 大字结论；
- 令牌掩码：`TOKEN  xxxx ****** xxxx`（已配对时）或 `No session token stored`；
- 状态行引导文字（未在范围内 / 已绑定只需复位后再配 / 提示按住车上按钮 3 秒后再点配对）。

配对成功后令牌保存在设备内（NVS），重启不丢失。

## 13. 颜色与状态速查表

界面遵循「**颜色 + 文字/图标** 双重表达」原则，色盲用户也能通过文字判断：

| 颜色 | 语义 |
|---|---|
| 🟢 绿 | 正常 / 就绪 / 已连接 |
| 🟡 琥珀 | 警告 / 数据陈旧 / 低电 / 无控制权 / 待确认 |
| 🔴 红 | 严重 / 故障 / 急停 |
| 🔵 蓝 | 信息 / 网页端控制 / 转向弧 |
| ⚪ 灰 | 无数据 / 未激活 / 已停 / 禁用 |
| 🟦 青（Accent） | 可交互元素 / 摇杆激活 / 油门弧 |

**按钮置灰（禁用）的含义**：执行条件不满足（如固件未暂存、链路断开、前置条件未确认），界面同时用提示行说明原因。

## 14. 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 顶栏一直 `SEARCHING` | 未连上 C6 Wi‑Fi | 检查设置 → RADIO 的 SSID/密码，点 APPLY + RECONNECT |
| 已连接但显示 `STALE` | 收到连接但遥测超时（>0.6 s 无帧） | 靠近小车、检查小车侧供电与 C6⇄TC275 链路 |
| 摇杆是灰的、推不动 | 未连接，或控制权在网页端 | 确认状态为 `CONNECTED` 且控制权为 `S3 MASTER` |
| 速度/电量显示 `--` | 数据超时 | 同 `STALE` 处理 |
| 想换驾驶模式 | — | 主页左列直接轻点 ECO / NORMAL / SPORT 按钮即选定 |
| 按了 STOP 后推摇杆没反应 | STOP 锁定需重新接管 | 重新触摸摇杆一次即可再驾驶 |
| 弹出红色全屏且只有 [RELEASE] | 紧急停止已触发 | 排除险情后点 [RELEASE] 解除 |
| 电量格变红 | 小车电量 ≤ 10% | 尽快停车充电 |
| FIRMWARE 页 UPDATE 按钮是灰的 | 暂存未 VERIFIED / 无控制权 / TC275 链路断 / 有更新进行中 | 看按钮上方提示行；先 PC 侧暂存镜像并 RESCAN，再建立 CTRL 链路 |
| CALIBRATE 页按钮全是灰的 | 前置条件不满足 | 连接并取得控制权、TC275 在线、亲手打开 WHEELS OFF GROUND 开关 |
| 找不到 DIAG / EVENTS 磁贴 | 工程模式未开 | SYSTEM 页 3 秒内 7 连击 S3 节点卡 |
| SYSTEM 页点 C6/TC275 卡显示 NO REPLY / NO BEACON | 链路断或节点不应答 | 先恢复链路再点一次；TC275 走信标，最长约 6.5 s |
| 开机自检某项停在灰 `-` | 对应子系统未就绪 | LCD/Touch=硬件；Radio=Wi‑Fi；重启或检修 |
