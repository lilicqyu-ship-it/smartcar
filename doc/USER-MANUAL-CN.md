# SMART CAR REMOTE — 用户操作手册（LCD UI 详解）

> 适用设备：ESP32‑S3 LCD‑EV‑Board 远距离智能遥控器（800×480 触摸屏）
> 本手册面向操作者，逐屏说明界面上每一项数据的含义与每一个设置的作用。
> 术语约定：**遥控器 / S3** 指手上这块屏；**小车 / TC275** 指被控车辆；
> **C6** 指小车上的 Wi‑Fi 网关模块。数据链路为：遥控器 S3 ⇄（Wi‑Fi）C6 ⇄ 小车 TC275。

## 1. 开机自检页（Boot）

上电后首先出现「SMART CAR / REMOTE CONTROLLER」标题页，中部是一条进度条与四项自检清单：

| 自检项 | 含义 | 通过标志 |
|---|---|---|
| **LCD** | 屏幕显示子系统就绪 | 右侧变绿色 ✓ |
| **Touch** | 触摸控制器就绪 | 右侧变绿色 ✓ |
| **Radio** | Wi‑Fi 无线电就绪 | 右侧变绿色 ✓ |
| **System** | 系统任务与状态机就绪 | 右侧变绿色 ✓ |

- 未通过项显示灰色「‑」，通过后变绿色对勾，进度条同步推进（满格 = 4/4）。
- 四项全部通过约 **0.6 秒** 后自动切换到驾驶主页，无需任何操作。
- 若某项长时间停在灰色「‑」，说明该子系统未就绪（见 [常见问题排查](#11-常见问题排查)）。

## 2. 驾驶主页（Home）— 核心操作屏

这是日常驾驶使用的主界面。布局分为：**顶栏**、**左侧遥测列**、**摇杆区**、**底部 STOP**。

```
┌──────────────────────────────────────────────┐
│ SMART CAR              CONNECTED    [⚙]       │ ← 顶栏
│ REMOTE CONSOLE         S3 MASTER              │
├──────────────────────────────────────────────┤
│  SPEED                       ┌───────────┐    │
│  +1.25            m/s        │           │    │
│  THR ▁▁█▁▁  +30%             │   摇杆     │    │
│  STR ▁▁█▁▁  -10%             │           │    │
│  BATTERY  MODE   STATE       └───────────┘    │
│  RSSI     PING   LOSS                          │
├──────────────────────────────────────────────┤
│                  [ STOP ]                      │ ← 底部固定
└──────────────────────────────────────────────┘
```

### 2.1 顶栏

| 元素 | 含义 | 取值与颜色 |
|---|---|---|
| **SMART CAR / REMOTE CONSOLE** | 产品标题（固定） | — |
| **连接状态**（右上第一行） | 遥控器与小车的链路状态 | `SEARCHING`(灰) 搜索中 · `CONNECTING`(蓝) 连接中 · `CONNECTED`(绿) 已连接且数据新鲜 · `STALE`(琥珀) 连着但数据超时 |
| **控制权**（右上第二行） | 当前谁在操控这辆车 | `S3 MASTER`(绿) 本遥控器持有控制权 · `WEB MASTER`(蓝) 手机网页端持有控制权 · `NO CONTROL`(琥珀) 无人控制 |
| **齿轮 ⚙** | 进入设置（指挥台） | 点击打开 |

> **关键规则**：只有当状态为 `CONNECTED` **且** 控制权为 `S3 MASTER` 时，摇杆才可驱动小车。其余情况下摇杆变灰、不可用（失效保护）。

### 2.2 SPEED（速度）卡

- 大号数字为当前车速，单位 **m/s**，带符号：`+` 前进、`-` 倒车（例如 `-0.05` 表示低速倒车）。
- 数据超时（`STALE` 或断链）时显示 `--`（灰色），绝不显示过期的假数据。

### 2.3 THR / STR（油门 / 转向）条

显示的是遥控器**实际发送出去**的控制量（不是摇杆的原始位置）：

| 项 | 含义 | 范围 |
|---|---|---|
| **THR**（Throttle 油门） | 前进/后退指令强度 | `-100%` ~ `+100%`，中心对称条 |
| **STR**（Steering 转向） | 左/右转指令强度 | `-100%` ~ `+100%`，`+` 右转、`-` 左转 |

条形为中心对称显示，正值向右、负值向左延伸。此处让你直观看到「油门是否非零」，避免误以为已停车实则仍有输出。

### 2.4 遥测网格（6 格）

第一行：

| 格 | 含义 | 说明 |
|---|---|---|
| **BATTERY** | 小车电池电量 % | 绿=正常 · 琥珀=低电（≤20%）· 红=极低（≤10%）；无数据显示 `--` |
| **MODE** | 当前驾驶模式 | `ECO` / `NORMAL` / `SPORT`（青色）。**可点击**：轻点此格即在三种模式间循环切换，并弹出 Toast 提示 |
| **STATE** | 车辆系统状态 | 见下表 |

第二行：

| 格 | 含义 | 说明 |
|---|---|---|
| **RSSI** | 无线信号强度（dBm） | 数值越接近 0 越强；标题会显示质量词 `EXC/GOOD/FAIR/WEAK/CRIT`。颜色随质量变化 |
| **PING** | 遥控器⇄C6 的往返延迟（ms） | 越低越好；断链时 `--` |
| **LOSS** | 遥测丢包率（%） | 越低越好；断链时 `--` |

**STATE（车辆状态）取值：**

| 显示 | 含义 | 颜色 |
|---|---|---|
| `BOOT` | 启动中 | 灰 |
| `LINKING` | 建立链路中 | 琥珀 |
| `READY` | 就绪，可驾驶 | 绿 |
| `DRIVING` | 行驶中 | 绿 |
| `WARNING` | 警告状态 | 琥珀 |
| `FAULT` | 故障 | 红 |
| `STOPPED` | 已停车锁定 | 灰 |
| `E-STOP` | 紧急停止 | 红 |

### 2.5 摇杆区

- **可用条件**：`CONNECTED` + `S3 MASTER`。满足时旋钮与外圈为青色高亮；否则整体置灰、无法输入。
- **操作**：手指按住旋钮拖动。
  - 向上 = 前进，向下 = 后退；向右 = 右转，向左 = 左转。
  - 松手后旋钮自动回弹到中心（约 160 ms 动画），控制量归零。
- **死区**：中心附近有一圈「死区」，在其中移动不产生输出，用来避免手指微抖导致小车缓行。死区大小可在设置中调整（见 §5.1）。
- **STOP 之后再驾驶**：按过 STOP 后，需**重新触摸摇杆**才会重新接管控制（防止松手误动）。
- **失链保护**：拖动中若断链，摇杆立即失效并回中；即使手指仍停在盘上，链路恢复后也不会突然复出行驶指令，必须抬手重按。

### 2.6 STOP 按钮（底部红色，固定不动）

STOP 是安全核心，位置固定、任何页面切换都不影响它：

| 操作 | 效果 |
|---|---|
| **轻点（短按）** | 普通停车：立即让小车停下并锁定，需重新触摸摇杆再驾驶 |
| **长按 ≥ 1.2 秒** | **紧急停止（E‑STOP）**：触发急停，弹出全屏告警，必须显式点击 [RELEASE] 才能解除 |

> 长按时长在遥控器内部计时；松开时判定是短按还是长按。若按压过程中被告警覆盖层挡住导致丢失按下事件，一律按短按处理，绝不会误触发急停。

## 3. 告警覆盖层（Alert）

当发生**安全相关**事件时，全屏弹出告警（普通信息不会弹，只在状态栏体现）。覆盖层带彩色背景 + 红色边框 + 图标 + 标题 + 说明 + 动作按钮。

| 告警等级 | 背景色 | 触发举例 |
|---|---|---|
| CRITICAL（严重） | 红 | 紧急停止、车辆故障 |
| WARNING（警告） | 琥珀 | 电量过低等 |
| NOTICE（提示） | 蓝 | 配对相关等 |

**动作按钮语义：**

- **[RELEASE]**（仅急停时）：解除紧急停止状态。
- **[ACKNOWLEDGE]**（其余告警）：确认知晓；若引发条件仍在，后续可能再次弹出。
- **无按钮（RADIO LOST 无线电丢失）**：链路完全丢失时不显示按钮——因为此时无可确认，告警会一直显示直到链路自动恢复。

## 4. 设置 · 指挥台（Command Deck）

点击主页右上齿轮 ⚙ 进入。左侧是 **SYSTEM CORE** 实时仪表，右侧是**模块磁贴**。

### 4.1 SYSTEM CORE（左侧圆环仪表）

| 元素 | 含义 |
|---|---|
| **圆环 + 中心数字** | 链路信号强度（dBm），圆环按 −90dBm=0% ~ −40dBm=100% 映射，颜色随质量变化 |
| **质量词** | `NO SIGNAL / EXCELLENT / GOOD / FAIR / WEAK / CRITICAL` |
| **LINK 芯片** | 遥控器⇄C6 链路：`LINK ON`(绿) / `LINK ...`(琥珀，连接中) / `LINK OFF`(灰) |
| **CAR 芯片** | C6⇄小车 链路：`CAR ON`(绿) / `CAR OFF`(灰) |
| **CTRL 芯片** | 控制权：`CTRL S3`(绿) / `CTRL WEB`(蓝) / `CTRL --`(琥珀) |
| **底部信息行** | 开机时长 `UP hh:mm:ss`、无线信道 `CH`、S3 固件版本、C6 固件版本 |

### 4.2 模块磁贴（右侧）

每块磁贴显示编号、图标、名称与**当前值副标题**（无需进入即可看到当前设置）：

| 磁贴 | 进入内容 | 副标题示例 |
|---|---|---|
| **01 CONTROL** | 驾驶模式 + 死区设置 | `NORMAL / DZ 8%` |
| **02 RADIO** | Wi‑Fi 连接与配对 | 当前 SSID |
| **03 DISPLAY** | 显示设置（只读说明） | `Dark HUD / always on` |
| **04 PAIRING** | 与小车配对 | `Bind to a car` |
| **05 ABOUT** | 版本信息 | `Firmware v…` |
| **06 DIAG**（工程模式） | 诊断内部信息 | `Link + vehicle internals` |
| **07 EVENTS**（工程模式） | 事件日志 | `Event log` |

> DIAG 与 EVENTS 磁贴默认隐藏，仅在**工程模式**下出现（见 §9）。

## 5. 设置子页详解

### 5.1 CONTROL（控制）

| 设置 | 作用 | 取值 |
|---|---|---|
| **Mode（模式）** | 缩放摇杆输出上限，限制最高速度/转向幅度 | **ECO**=最大输出 50% · **NORMAL**=80% · **SPORT**=100% |
| **Dead zone（死区）** | 摇杆中心不响应的范围，避免手指抖动导致缓行 | 滑条 `0% ~ 30%`，默认 8% |

- 模式为**遥控器端的软限幅**，实际动力调校在车辆端完成。
- 死区在**按下摇杆的瞬间**采样生效；拖动滑条实时显示数值，松手后保存到设备（掉电不丢）。

### 5.2 RADIO SETUP（无线电设置）

| 元素 | 作用 |
|---|---|
| **C6 AP SSID** | 小车 C6 网关的 Wi‑Fi 名称（出厂默认 `SD-DEV000`，量产机看车身标签） |
| **Password** | 该 Wi‑Fi 的密码（密文显示） |
| **[APPLY + RECONNECT]** | 保存 SSID/密码并立即重连 |
| **[PAIR WITH VEHICLE]** | 发起与小车的配对（等同配对页的按钮） |
| **状态行** | 显示当前配对/连接反馈 |

- 点击输入框弹出软键盘；点击别处收起。
- 设置保存到设备内部存储（NVS），重启后依然生效。

### 5.3 DISPLAY（显示）

本页为**只读说明**，本硬件不提供可调项：

| 项 | 值 | 说明 |
|---|---|---|
| **Theme** | `DARK (default)` | 固定深色 HUD 主题 |
| **Brightness** | `fixed on this panel` | 该 EV 板背光为硬件常亮，无软件亮度调节 |

驾驶时屏幕保持常亮（不会黑屏）。

### 5.4 ABOUT（关于）

显示产品与版本信息：

| 项 | 内容 |
|---|---|
| **Controller** | ESP32‑S3 |
| **Radio** | WiFi → C6, proto v2 |
| **Vehicle** | TC275 via C6 |
| **Firmware** | 遥控器固件版本 |

> **工程模式解锁**：在 3 秒内连续点击 **Firmware（固件版本）** 那一行 **7 次**，即弹出 `ENGINEER MODE ON` 提示，设置指挥台随即多出 DIAG 与 EVENTS 两个磁贴。

## 6. 车辆信息页（Vehicle）

集中显示小车侧的详细遥测。数据超时时全部显示 `--`。

**DRIVE（驾驶）**

| 项 | 含义 |
|---|---|
| **State** | 车辆原始状态码 `0x??`，末尾 `(no link)` 表示 C6 与小车链路断开 |
| **Speed** | 车速 m/s（带符号） |
| **Throttle** | 实际发送的油门 % |
| **Steering** | 实际发送的转向 % |
| **Mode** | 当前驾驶模式 |

**POWER（动力）**

| 项 | 含义 |
|---|---|
| **Battery** | 电量 % |
| **Battery voltage** | 电池电压 V |
| **Odometer (session)** | 本次会话里程（m） |

**VEHICLE CORE（车辆核心）**

| 项 | 含义 |
|---|---|
| **Fault** | 故障码：`NONE`(绿) 无故障 / `0x????`(红) 有故障 |
| **TC275 firmware** | 小车主控固件版本 |
| **HW revision** | 硬件版本号 |

## 7. 无线电页（Radio）

展示链路质量的完整明细。

| 项 | 含义 |
|---|---|
| **状态行** | `SEARCHING/CONNECTING/CONNECTED/STALE` |
| **RSSI** | 信号强度 dBm + 图形条（−100dBm→0%，−40dBm→100%），颜色随质量 |
| **Quality** | 质量词 `EXCELLENT/GOOD/FAIR/WEAK/CRITICAL` |
| **Latency (S3‑C6)** | 遥控器⇄C6 延迟：当前值，及括号内 `min/max` |
| **Loss** | 遥测丢包率 % |
| **TX rate** | 每秒发送的 DRIVE 控制帧数（Hz） |
| **RX rate** | 每秒接收的遥测帧数（Hz） |
| **Telemetry seq** | 最新遥测端到端序号 |
| **Channel** | Wi‑Fi 信道号 |
| **Peer (C6 fw)** | C6 网关固件版本 |
| **C6‑TC275 RTT** | C6 与小车间链路往返时延（ms），括号内为错误率 % |

**信号质量阈值（出厂默认，量产前需实测标定）：**

| 质量 | RSSI 门限 |
|---|---|
| EXCELLENT | ≥ −60 dBm |
| GOOD | ≥ −67 dBm |
| FAIR | ≥ −75 dBm |
| WEAK | ≥ −85 dBm |
| CRITICAL | < −85 dBm |

## 8. 配对页（Pairing）

将遥控器绑定到一辆小车。按屏幕三步引导操作：

1. 给小车上电并保持在通信范围内；
2. 长按小车上的配对按钮 3 秒；
3. 在配对窗口开启期间，点击本页的 **[PAIR WITH VEHICLE]**。

状态行反馈：`Not paired.`（未配对）/ `Paired. Token stored.`（已配对，令牌已保存）或实时配对进度。配对成功后令牌保存在设备内，重启不丢失。

## 9. 诊断页与事件日志（工程模式）

### 9.1 DIAGNOSTICS（诊断）

| 分区 | 项 | 含义 |
|---|---|---|
| CONTROLLER (ESP32‑S3) | Firmware | 遥控器固件版本 |
| | Heap free | 剩余内存 KB |
| | PSRAM free | 剩余 PSRAM KB |
| | Uptime | 开机时长 |

| | TC275 state | 车辆状态码 |
| | C6 firmware | C6 固件版本 |

### 9.2 EVENT LOG（事件日志）

- 按时间倒序显示系统事件（最多 32 条），格式：`时:分:秒  事件文本`。
- 按等级着色：红=严重、琥珀=警告、蓝=提示、灰=普通信息。

## 10. 颜色与状态速查表

界面遵循「**颜色 + 文字/图标** 双重表达」原则，色盲用户也能通过文字判断：

| 颜色 | 语义 |
|---|---|
| 🟢 绿 | 正常 / 就绪 / 已连接 |
| 🟡 琥珀 | 警告 / 数据陈旧 / 低电 / 无控制权 |
| 🔴 红 | 严重 / 故障 / 急停 |
| 🔵 蓝 | 信息 / 网页端控制 |
| ⚪ 灰 | 无数据 / 未激活 / 已停 |
| 🟦 青（Accent） | 可交互元素 / 摇杆激活 |

**`--` 的含义**：数据超时或链路未建立，界面故意显示 `--` 而非过期的假值。

## 11. 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 顶栏一直 `SEARCHING` | 未连上 C6 Wi‑Fi | 检查设置 → RADIO 的 SSID/密码，点 APPLY + RECONNECT |
| 已连接但显示 `STALE` | 收到连接但遥测超时（>0.6s 无帧） | 靠近小车、检查小车侧供电与 C6⇄TC275 链路 |
| 摇杆是灰的、推不动 | 未连接，或控制权在网页端 | 确认状态为 `CONNECTED` 且控制权为 `S3 MASTER` |
| 速度/电量显示 `--` | 数据超时 | 同 `STALE` 处理 |
| 按了 STOP 后推摇杆没反应 | STOP 锁定需重新接管 | 重新触摸摇杆一次即可再驾驶 |
| 弹出红色全屏且只有 [RELEASE] | 紧急停止已触发 | 排除险情后点 [RELEASE] 解除 |
| 电量格变红 | 小车电量 ≤ 10% | 尽快停车充电 |
| 找不到 DIAG / EVENTS | 工程模式未开 | ABOUT 页 3 秒内 7 连击固件版本行 |
| 开机自检某项停在灰 `-` | 对应子系统未就绪 | LCD/Touch=硬件；Radio=Wi‑Fi；重启或检修 |
