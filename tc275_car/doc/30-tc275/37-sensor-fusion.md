# 37 · 传感器融合与遥控驾驶辅助

版本 V1.5，2026-10-09；本次为驾驶体验策略调整，未发布新版本或烧录。用户确认 ToF 朝车头。

## 已落地的行为（2026-10-09）

CPU0 每 10 ms 在 ROBOT 心跳/故障处理后读取编码器、IMU、ToF 快照并计算电机目标。CPU1 保留 1 kHz 编码器闭环及斜坡；CPU2 上报。

- **限速门槛**：完全可信区域数必须严格超过总区域数的 **2/3**。完全可信 = `targets>0`、原始状态 **5**、原始距离 1–4000 mm。分母固定为整个网格：4×4 至少 **11/16** 区，8×8 至少 **43/64** 区。状态 9、无目标、异常状态和越界距离不算完全可信。
- **降速区间**：满足上述门槛后，以完全可信区的最近原始距离限速；**距离 ≥150 mm 不限速，60–150 mm 线性降速，距离恰好 60 mm 保留最小正目标**。相同比例缩放两侧目标，保留遥控曲率。
- **其他可用帧忽略 ToF 限速要求**：完全可信覆盖 ≤2/3 时，上限为当前遥控 `fullScaleMmS`，不执行原有 150 mm/s 爬行、连续衰减或空旷 600 mm/s 限制。原始目标直接通过 ToF 限速环节。
- **障碍停车**：任一有效区域原始距离**严格 <60 mm**，前进立即制动并锁存；此硬停独立于覆盖率。状态 5 或 9、目标数非零、原始距离 1–4000 mm 才属于有效测距。状态 9 在距离遥测里仍保守减 50 mm，但这个修正值**不参与 60 mm 停车判断，也不参与限速距离**，避免实际 100 mm 被误判为 50 mm。
- **取消包络超速提前停车**：车轮实际速度超过 ToF 限速值时只降低目标，不再因此锁存障碍停车；正常急停与其他失效保护独立保留。
- **锁存恢复**：连续 3 个不同新帧中最近有效原始距离 ≥80 mm（或无有效目标），并且摇杆归零，才解锁。重复读取同一帧不累计恢复；一直按住前进不会自动重启。
- **失效保护保留**：ToF `alive=0`、序号未发布、帧龄 >250 ms 或网格非法时禁止前进；编码器发布失活/被驱侧 500 ms 无边沿/车轮未标定、倾斜、用户急停仍按各自规则处理。忽略低可信度限速不等于忽略传感器失效。
- 倒车仍独立限速 250 mm/s；含正向轮目标的原地转向走上述前向保护。松杆/STOP/心跳超时归零后立即制动，静止待命不持续制动。

ToF 内部四态继续用于诊断：TRACKED = 有有效测距；OPEN = 无有效目标且无目标比例 ≥70%、未知比例 ≤30%，连续三个新帧确认；DEGRADED = 状态不确定；BLIND = 无可用帧。**四态不再自行决定爬行或空旷速度上限**。flags=1 表示完全可信区 >2/3、可参与限速；flags=128 表示可用但不满足该门槛、忽略限速。两者仍保持 `(flags & 129)` 的非盲区判定，28 B 载荷布局不变。

## 融合保护主开关（v1.3.2，台架/诊断旁路）

`app/fusion.h` 的编译期宏 `FUSION_CFG_PROTECTION`（默认 1，可用 `-D` 覆盖）：

- **1（默认，生产构建）**：全部保护行为不变。
- **0（旁路）**：`FUSION_step` 在场景分类、制动包络 cap、健康位与速度锚计算完成后**提前返回**——这些遥测照常发布，`[FUSION]` 日志新增的 `protection=0` 字段与之配套；但**不执行任何干预**：限速、停车锁存（近障/盲区/编码器丢失/超速）、45° 倾斜停车、250 mm/s 倒车限速全部关闭，`effective[]` 直通钳位后的原始请求；松杆仍保留立即制动位。锁存状态在旁路下强制清零，重新启用保护时从净状态起步。

动机（2026-10-05）：ToF 安装高度 48 cm、水平朝前，8×8 视场（45°×45°）最下排区域的地面回波落在 ~0.95–1.4 m——地面永远够不到 220 mm 近障线（垂直往下看都要 ≥480 mm），却足以把动态包络 cap 压到满量程以下，**重新武装** v1.0.9 只对 `cap==fs` 豁免的超速锁存：地面场景满杆跑出自由转速即假锁存 `stop_obstacle`，且 OPEN_CLEAR 空旷放行被地面回波永久打破。旁路开关让车在地面照常驾驶、`[FUSION]`/`[TOF_ZONE]` 继续记录"保护本会怎么做"，用于定位该问题（长期修复候选：按安装高度的地面平面过滤 / 传感器上仰 ≥10–16° / `fullScaleMmS` 实测标定）。**旁路构建没有任何前向保护，仅限台架与受控场地使用**；测试完成必须恢复默认 1 并重烧。

验证：`test_fusion`（默认 1，既有回归全过）+ 新增 `test_fusion_bypass`（以 `FUSION_CFG_PROTECTION=0` 直接包含生产 `fusion.c`，断言近障/超速假锁存/编码器失效/盲区/倒车全部直通、遥测与松杆制动保持、锁存永不置位）入 CI；TASKING Debug 构建通过（ROM 199042 B，v1.3.2）。

## 距离与目标速度

单位固定：协议 ±100，电机目标 ±1000（pct×10），速度 mm/s，距离 mm。设完全可信区最近原始距离为 `d`，当前标定满量程为 `fs`：

```
完全可信区 <=2/3：cap = fs
完全可信区 >2/3 且 d >=150：cap = fs
完全可信区 >2/3 且 60 <=d <150：cap = max(ceil(fs/1000), floor(fs*(d-60)/90))
任一有效区原始距离 <60：前进立即停车（不依赖覆盖率）
ToF 无可用帧：cap = 0，前进走失效停车
```

最低正上限避免 60 mm 边界因整数换算提前归零；它只是电机目标，不保证实际车轮一定能克服静摩擦。降速仅收紧超过上限的请求，不自动提高较小的摇杆目标。10 cm 时上限约为满量程的 44%，12 cm 时约 67%。

本策略替代旧的 220 mm 余量、制动距离包络、覆盖不足爬行和包络超速停车。60 mm 是传感器测距，未扣除保险杠位置；实际停车距离与安装偏移仍需实车验证，主机测试不能证明该距离下的防碰撞能力。

## IMU 与编码器融合、后续标定

`app/fusion.c` 是纯 C99 算法，`FUSION_calibrate()` 提供 CPU0 停车时使用的标定入口：三个有符号轴编号 ±1..±3，将传感器轴映射到车体 X前/Y左/Z上；必须是右手坐标系；轮距为实测 80–600 mm。iOS 传感器页使用水平与抬起车头两次静止采样推断轴向，DPT 0x7A 在车端停车且 IMU 在线时接纳并延迟写入同一 DFlash 标定记录；CPU0 控制任务依据 RecordLive 应用映射，EVT 0x23 扩展字段回传轴向、轮距和最终保存结果。旧 v1 车轮记录可读取，IMU 映射按未标定处理。IMU 单独写入 DFlash 不代表车轮已判向；独立 `wheelCalibrated` 位继续控制 CPU1 闭环及融合车轮有效性。`straightAssist` 仍另行显式开启。

当前未标定仍可学习传感器原始三个轴的静止陀螺零偏：连续 2 s 无驾驶指令、编码器计数不变、两侧速度 ≤10 mm/s、加速度模 0.9–1.1 g、各陀螺 ≤5°/s，然后积累至少 100 个新样本。

编码器健康按侧判定（v1.3.1，根因与推导见 [51](../51-encoder-health-bugfix.md)）：发布序号只证明 CPU1 发布任务活着（编码器全死也每毫秒自增），不能证明传感器活着；真正的健康原语是每侧"距最近边沿的毫秒数"（快照 `edgeAgeMs[2]`）。被驱动（请求非零）的侧必须持续出边沿，允许 500 ms 起步宽限（轮子从静止起动需要时间；松杆即清零，静止待命永不误报）；边沿龄 ≤100 ms 视为新鲜。速度锚只用边沿新鲜的侧（死侧的假 0 不再平均进车速）；轮速/陀螺一致性检查要求两侧同时新鲜。旧的单个 `alive` 位保留为"近期有运动"指示，不再参与失效判定。

标定后提供：

- 陀螺预测 + 加速度重力修正的横滚/俯仰互补滤波；强加速度期间暂停重力修正。适用于低速、小倾角地面小车，不是完整惯导。
- 零偏校正陀螺与编码器差速角速度融合；一致时 85% 陀螺 +15% 编码器；差异超过 30°/s 标记轮速与陀螺不一致，角速度更信任陀螺，暂停直行修正。
- 相对航向积分与直行航向保持；限幅修正 ±80 pct×10 且不超过较慢一侧目标的 25%，之后再次执行距离限速，不能用纠偏突破安全速度。
- 完成零偏学习且 IMU 新鲜时，横滚或俯仰超过 45°触发倾斜停车。

六轴 IMU 无绝对航向观测，不声称具有绝对方位或无漂移定位。编码器不一致标记是诊断线索，不能区分打滑、轮距错误与标定错误。当前姿态/航向反馈不参与车轮控制，等待安装标定。

## 数据并发与链路

ToF 完整帧含距离、状态、目标数、发布序号及 CPU0 毫秒时间戳，复制到 xcore 后才可被高优先级控制任务读取，避免半帧。编码器发布序号由 xcore 自增，包括静止时的发布。

xcore 全局锁现在先保存并屏蔽各核中断，再获取硬件互斥，释放后恢复原中断状态；只在有界 RAM 复制期间持锁，不在总线/等待/数学运算期间持锁。这样 CPU0 高优先级控制任务不能抢占同核持锁 ToF 任务后永远自旋。

保留原 38 B 0x41 遥测布局。CPU2 同时观察 CPU0 快照时间戳是否继续变化，超过 250 ms 不变化时清除传感器新鲜位、前进上限归零，不能由持续网络流量把冻结数据伪装为新鲜。CPU2 仅 LINK_READY 时每 200 ms 读取最新融合快照，发送 `SF EVT CID 0x27`，不占 CPU0 校准事件队列。载荷版本 1，长度 28 B，所有多字节小端：

| 偏移 | 字段 | 单位 |
|---|---|---|
| 0 / 1 | 版本 / reason | u8 |
| 2 | flags | u16 |
| 4 / 6 | 最近距离 / 前进限速 | mm / mm/s，u16 |
| 8 / 10 | 车速 / 偏航角速度 | mm/s / 0.01°/s，i16 |
| 12 / 14 / 16 | 相对航向 / 横滚 / 俯仰 | 0.01°，i16 |
| 18 | ToF 帧龄 | ms，u16 饱和 |
| 20 / 22 / 24 | 外列组 / 中心列组 / 外列组距离 | mm，u16；光学安装方向未标定，不用于选择绕行方向 |
| 26 / 27 | 有效区域数 / 制动位 | u8 |

flags 位值：1 ToF 完全可信区严格 >2/3（状态 5、目标数非零、原始距离有效）、2 IMU新鲜、4 编码器反馈健康（发布新鲜且被驱侧 500 ms 内有边沿，[51](../51-encoder-health-bugfix.md)）、8 轴向已标定、16 轮速/陀螺不一致、32 零偏就绪、64 松开前进后重新起步、128 ToF 帧可用但完全可信覆盖不足，此时忽略 ToF 限速；TRACKED/DEGRADED/OPEN 为诊断分类，不改变该门槛。reason：0 无干预、1 限速、2 近障/停车锁存、3 前方未知、4 倾斜、5 车速反馈未就绪。无驾驶指令时 reason 可为 0，客户端同时检查 flags 和 cap，不把 reason=0 等同于可前进。

C6 通过现有 DIAG 隧道解码成 `t:fusion` JSON，网页显示距离、速度上限、停车原因、待标定姿态；1 s 没有更新则显示过期。短载荷、未知版本丢弃。iOS 原生端新增首页覆盖不足、保护停车及过期提示；S3 手持端原遥控协议兼容。
